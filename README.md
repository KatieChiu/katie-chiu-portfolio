# Katie Chiu — Portfolio

Personal portfolio of **Katie Chiu**, Systems Engineer and Full-Stack Software Developer.

The portfolio showcases my professional experience, academic projects, technical skills and selected software development projects.

## About

I'm a **Systems Engineer and Full-Stack Software Developer** focused on building web applications, REST APIs and business solutions.

My experience covers frontend and backend development, database design, software architecture, integrations and the development of solutions based on real-world business requirements.

The portfolio also includes academic projects developed throughout my degree in Systems Engineering, including:

* **Sistema de Gestión de Permisos** — Python and Odoo modules for digitizing and automating employee permission requests at UNAH-Comayagua.
* **Sistema de Gestión de Horas VOAE** — Web application developed as an assignment for Object-Oriented Programming using C#, .NET Core and DevExtreme.
* **Medical Diagnosis Risk Assessment** — Undergraduate thesis research focused on semantic embeddings and risk assessment of LLM-generated medical diagnosis responses using SBERT and FAISS.
